# 💬 ChatX – Real-Time Chat Application (MERN Stack)

ChatX is a real-time chat app built with **MongoDB, Express, React, Node.js**, and **Socket.io**.  
It lets users register, log in, chat one-on-one or in groups, and see messages instantly.

---

## 🚀 Features

- **User Management**: Register, log in, and manage profile pictures.
- **Real-Time Chat**: Private and group chats using Socket.io.
- **Group Chat Management**: Add/remove members, rename groups, and assign admins.
- **Notifications**: Get notified of new messages.

---

## 🛠️ Tech Stack

- **Frontend**: React, Chakra UI, Axios  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB (Mongoose)  
- **Realtime**: Socket.io  
- **Authentication**: JWT  
- **Cloud Storage**: Cloudinary (profile pictures)
